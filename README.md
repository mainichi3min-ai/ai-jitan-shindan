# 30秒でわかる！AI時短ツール診断

「毎日3分AI時短ラボ」の収益化導線用Webアプリです。4つの質問に答えると、おすすめの無料AIツール3選と時短シミュレーション結果を表示します。DBなし・静的サイト（HTML / CSS / JavaScript）で動作します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造（スタート／質問／ローディング／結果） |
| `style.css` | デザイン（メイン #1E3A8A、アクセント #0D9488） |
| `script.js` | 診断ロジック・ツールデータ・リンク設定 |

## リンクURLの書き換え方法（重要）

差し替えは **`script.js` の上部だけ** で完結します。

1. **有料noteのリンク**: `script.js` 冒頭の `CONFIG.noteUrl`（現在は `https://note.com/mainichi3min_ai`）。有料記事を公開したら、その記事のURLに書き換えます。
2. **おすすめツールのリンク（アフィリエイト対応）**: `script.js` の `TOOLS` 配列の各 `url` が公式URLになっています。ASPで提携できたら、該当ツールの `url` をアフィリエイトURLに書き換えるだけです（表示や診断ロジックは変わりません）。
3. **シェア文面に自サイトURLを付ける**: 公開URLが決まったら `CONFIG.siteUrl` にそのURLを入れると、X／Threadsのシェア文面に自動で付きます。

## 診断ロジックの概要

- Q1 職種、Q2 一番時間を使っている作業、Q3 AI利用経験、Q4 重視ポイント
- カテゴリ加点（文章／リサーチ／資料／スライド／データ）＋ツール個別加点で上位3ツールを選出
- 時短シミュレーション: Q2の想定週時間 × 削減率（Q3: 初心者30%／たまに40%／毎日50%）→ 週・月（×4.33）の削減時間を表示。画面には「目安」と明記

## GitHub Pagesで無料公開する手順（3ステップ）

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch に **main / (root)** を指定して Save
3. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。そのURLを lit.link のボタンと `CONFIG.siteUrl` に設定してください

※ GitHub Pagesを無料で使うにはリポジトリを **Public** にする必要があります（コードに秘密情報は含まれていません）。

## 注意

- アフィリエイトリンクを使う場合は、アプリ内または誘導先でPR表記（広告である旨の表示）が必要です（ステマ規制対応）。
- 投稿・結果画面の文面に外部URLを含める運用は、SNS各アカウントのウォームアップ期間（開設後7日間）終了後、オーナーの解禁指示がある場合のみ行ってください。
